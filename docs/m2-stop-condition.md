# M2 Stop Condition

Stop M2 once ViewWright can carry one coherent semantic visual profile from canonical TOML through resolution into both concept specification and egui.

Do not continue expanding style vocabulary merely because a renderer could use more controls.

After M2, any additional visual abstraction should be earned by a new real specimen whose needs cannot be expressed cleanly with:

- palette roles
- type scale
- surface roles
- border/corner policy
- spacing
- importance
- design character / avoidances

In particular, do not preemptively add selectors, classes, component styles, theme inheritance, shadows, gradients, or per-widget overrides.
