# M13 — Roadmap Note

M13 deliberately narrows the composition contract to semantics the current engine can actually project.

`stack` and `overlay` remain potentially useful future composition kinds, but they are not part of M13 because ViewWright has not yet earned their geometry, z-order, overlap, hit-testing, or projection semantics. Re-admitting either value requires a future milestone with explicit pressure and acceptance evidence.

Likewise, M13 does not decide future alignment, grid, responsive, constraint, or absolute-positioning systems.
