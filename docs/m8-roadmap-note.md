# M8 — Roadmap Note

M8 is intentionally a fidelity milestone rather than a vocabulary-expansion milestone.

The repository already contains the authoring word `presentation` and already contains accepted canonical values `list` and `adaptive_cards`.

The work is to make those existing declarations truthful:

- validate them;
- resolve them into typed semantics;
- expose them to semantic/concept projections;
- make the egui backend honor the distinction.

No source migration is expected beyond any cleanup needed to keep accepted canonical declarations explicit and valid.
