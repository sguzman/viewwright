# M40 — Canonical Audit

## New source

M40 may add one new pressure specimen representing Lantern Leaf within the current ViewWright language.

That specimen is canonical **as the ViewWright 0.1 baseline approximation**, not as a claim that every Lantern Leaf concept detail is represented.

## External source

Lantern Leaf's furnishing remains external pressure evidence.

Do not vendor it into ViewWright and do not make ViewWright depend on Lantern Leaf.

## Existing sources

Do not rewrite existing Project Browser, Reader, overlay, overflow, or density specimens to make M40 easier.

## Historical releases

Do not modify or move the `v0.1.0` tag.

M40 is post-release work toward v0.2.
