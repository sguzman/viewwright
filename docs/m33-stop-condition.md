# M33 — Stop Condition

Stop M33 once ViewWright can deterministically export one honest intended expectation document from a resolved blueprint + explicit logical viewport.

Stop when:

- the artifact is clearly marked `intended`;
- it is not a ViewWitness `Witness`;
- root-reachable region/element identity is preserved;
- unused declarations are omitted from visible expectations;
- region bounds exactly match LayoutPlan;
- dominant target identity survives;
- region overflow intent survives;
- element labels/kinds/importance/command actions survive without invented bounds;
- Project Browser, overlay pressure, and overflow pressure exports are regression-tested;
- identical input + viewport yields byte-stable YAML;
- existing canonical blueprints require no migration;
- all M0–M32 tests remain green.

Do not continue into expectation-vs-witness comparison, matching heuristics, tolerances, pass/fail verification, runtime identity injection, fixture expectations, responsive variants, or M34 after this condition is met.
