# Changelog

## 0.1.0

The first release checkpoint for the accepted ViewWright M0–M38 system.

### Shipped

- Declarative TOML blueprints with typed parsing, strict validation, resolution, semantic/debug output, and stable authored identity.
- Semantic screens, regions, elements, composition, representative fixtures, and isolated egui preview.
- Backend-independent layout planning and ASCII, concept-specification, and visual-audit projections.
- Authored visual tokens and semantic surfaces; commands/interactions, search, density, list/adaptive-card collections, overlays, and vertical overflow.
- AccessKit author identity from the egui renderer, typed normative expectation export, and exact comparison with descriptive ViewWitness observations.
- Test-proven end-to-end verification of real renderer output against expectations for ordinary, overlay, and overflow cases.

### Intentional deferrals

Responsive authoring (roadmap [Issue #33](https://github.com/sguzman/viewwright/issues/33)), live ViewWitness observer/server capture, public runtime verification APIs, CI verification gates, fuzzy/tolerant or screenshot comparison, richer fixture-aware expectation semantics, backend-independent element geometry, additional GUI backends, and general application-state/data-binding systems are not part of this release checkpoint.
